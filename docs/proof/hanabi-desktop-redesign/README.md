# Hanabi desktop redesign proof

This folder records the acceptance proof for the desktop Hanabi game surface implemented by epic `hanabi-b30`. The wide layout activates at 1280 CSS pixels and mounts a single three-column composition: chronological per-color tableau, split player workspaces, and persistent activity rail. Narrower widths retain the prior composition.

## Final captures

- `desktop-standard.png`: representative four-player game at 1586×992.
- `desktop-maximum-state.png`: five players, seven active colors, ten chronological red discards, and natural vertical page scroll at 1280×900.
- `desktop-chat.png`: activity fixture with Chat selected at 1280×900.

## Refinement pass

The first live integration showed two concrete problems. The dark desktop surface leaked light text into the legacy white feed one pixel below the breakpoint, so the surface treatment became breakpoint-aware. The first tile motif competed with live numerals, so face art opacity was reduced to 16% while the concealed-card rosette retained 44% contrast. Live multiplayer proof also exposed that the permission extraction had accidentally limited action menus to the local hand; restoring turn-owner access to other players' tiles re-enabled clue actions without making remote tiles draggable.
